- 勋章功能预留位置稍后晚点实现也可以
- 对局终局记录预留位置稍后晚点实现也可以
- 实现基于 LAN 的局域网对战功能。但是请记住后续我们要支持 Internet 和 MultipeerConnectivity 对战，所以请预留接口和扩展空间，增强代码复用性

UX 设计上，应该是这样的体验：
- 用户首次进入 APP，弹出欢迎页面，提示输入一个昵称
- 用户进入首页，首页可以选择对战模式，目前只可以选 局域网对战
- 局域网对战页面可以选择
  - 创建房间
  - 加入房间
- 创建房间后，用户可以选择房间名称和房间密码（可选），然后等待其他玩家加入
- 全部玩家进入房间后，房主可以点击开始游戏，进入游戏配置和模式选择页面，其他玩家进入等待页面实时查看房主的选择。目前游戏配置页面可以选择游戏模式（正常版、丝绸之路扩展版、双人版）但是此时只开放正常模式。以及是否添加人机（预留页面接口和未来的人机对战接口，但是此时不开放人机对战功能）人机你可以考虑一下是在游戏配置页面选择，还是在游戏配置之前大家加房间的时候加入人机。人机支持难度调整。哦对！还可以配置胜利条件，这个是依照游戏模式的选择而有不同选项的，但是目前只有正常版：配置胜利分数。游戏规则还可以配置每个操作的时间限制秒数，默认 30 秒。
- 然后就是正常的游戏页面。
- 界面要大气，多语言，尽量使用原生组件。
