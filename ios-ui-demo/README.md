# 璀璨宝石 iOS UI Demo

一个使用 SwiftUI 制作的基础版璀璨宝石竖屏界面演示。项目只包含本地假数据，不包含规则引擎、联网、账号或持久化能力。

## 运行

1. 使用 Xcode 打开 `SplendorUIDemo.xcodeproj`。
2. 选择 iPhone 14 或更新的 iPhone 模拟器。
3. 运行 `SplendorUIDemo` Scheme。

最低系统版本为 iOS 17，应用仅声明支持 iPhone 竖屏。

## 演示交互

- 点击入口按钮进入对局；返回后重新进入会重置所有假数据。
- 点击箭头或左右滑动，在 6 名对手之间循环切换。
- 点击五色公共宝石后可确认拿取或取消；同一颜色连续点击两次可选择 2 枚，黄金只展示库存。
- 点击贵族可查看放大信息。
- 点击发展卡可选择购买、预留或取消；这些动作只显示提示，不修改卡牌数据。
- 点击底部左侧的分数/预留区域，可以查看当前预留的发展卡列表。
- 点击对手面板可以查看该对手预留的发展卡。
- 绿色细描边表示按照当前假资源计算后可以购买的发展卡；三级牌库余量显示在公共卡牌上方。

## 测试

`SplendorUIDemoTests` 覆盖假数据规模、对手循环、宝石拿取、黄金禁选以及卡牌操作不修改数据等状态行为。
